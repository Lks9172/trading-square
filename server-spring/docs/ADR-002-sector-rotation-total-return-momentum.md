# ADR-002: 섹터 순환 상대강도에 총수익률 위험조정 모멘텀을 사용한다

- 문서 상태: **DECISION**
- 상태: **Accepted / production**
- 결정일: 2026-08-08
- 운영 버전: `CURRENT_TOTAL_RETURN_RISK_ADJUSTED_MOMENTUM_WALK_FORWARD_V2`
- 비교 전용 버전: `CURRENT_TOTAL_RETURN_RS_WALK_FORWARD_V1_COMPARISON_ONLY`
- 관련 PDR: [`../../docs/PDR-001-sector-rotation-product-interpretation.md`](../../docs/PDR-001-sector-rotation-product-interpretation.md)
- 후속 증거 무결성 결정: [`ADR-003`](ADR-003-sector-rotation-evidence-integrity.md)
- 상세 산식: [`../../docs/SECTOR-ROTATION-METHODOLOGY-V2.md`](../../docs/SECTOR-ROTATION-METHODOLOGY-V2.md)

## 맥락

기존 섹터 순환 상대강도는 1·3·6·12개월 가격 수익률을 혼합했다. 이 방식에는 다음 문제가 있었다.

1. 배당이 큰 금융·에너지·유틸리티·필수소비재 섹터를 장기 비교할 때 가격수익률이 경제적
   총수익률을 과소평가한다.
2. 현재 UI 산식과 기존 5년 백테스트 산식이 달라, 과거 적중률을 현재 모델의 검증 결과처럼
   오해할 수 있었다.
3. 단기 1개월 수익률이 중기 추세 점수를 흔들고 변동성이 큰 섹터를 과도하게 상위에 올릴 수 있었다.
4. SPY 대비 적중률만으로는 시장 전체 상승과 섹터 선택 효과를 분리하기 어려웠다.
5. 거시·이익추정·수급의 완전한 point-in-time 이력이 없는 상태에서 전체 섹터 순환 모델이
   검증됐다고 표시할 위험이 있었다.

필요한 결정은 단순히 점수를 높이는 산식을 고르는 것이 아니라, 운영 산식과 검증 산식을 일치시키고
검증 범위를 제품에 정직하게 노출하는 것이었다.

## 결정

### 1. 기준 데이터

- 표준 섹터 ETF 11개와 SPY의 Yahoo `adjclose`를 분배금 재투자 **총수익률 프록시**로 사용한다.
- 섹터와 SPY가 같은 거래일에 모두 존재하는 관측치만 정렬해 사용한다.
- 최대 공통 이력을 확보하기 위해 9년을 요청하고 시계열별 최소 2,000개 관측치를 운영 계약으로 둔다.
- 공급자가 바뀌거나 최신일 정렬이 깨지거나 최소 이력이 부족하면 해당 신호를 억지로 계산하지 않는다.

`adjclose`는 세금, 실제 거래비용, ETF 구성 변경을 완전히 재현하는 공식 총수익지수는 아니다. 따라서
API와 UI에서는 `ADJUSTED_CLOSE_TOTAL_RETURN`이라고 명시하고 공급자 지수를 그대로 복제한다고 주장하지 않는다.

### 2. 운영 상대 모멘텀 산식

완료된 월말 또는 최신 공통 거래일 기준으로 다음을 계산한다.

1. 최근 1개월을 제외한 섹터/SPY 6개월 상대 총수익률
2. 최근 1개월을 제외한 섹터/SPY 12개월 상대 총수익률
3. 두 값을 각각 50%로 결합
4. 직전 252거래일 섹터/SPY 로그 상대수익률의 연율화 변동성으로 나눔
5. 표준 11개 섹터 횡단면 백분위로 0~100 `momentum score` 생성

두 형성 기간 중 하나라도 부족하면 나머지 하나로 대체하지 않는다. 현재 주도 판정에는 다음 조건도
필요하다.

- 중기 상대 총수익률이 0 이상
- 위험조정 모멘텀 백분위가 65 이상
- 최근 1개월 제외 12개월 절대 총수익률이 양수
- 최신 조정주가가 200거래일 평균 위

이 산식은 MSCI와 S&P의 모멘텀 방법론에서 공통적으로 사용하는 최근 1개월 제외, 중기 형성 기간,
변동성 조정 원칙을 섹터/SPY 상대 총수익률에 맞게 적용한 **내부 프록시**다.

### 3. 검증 계약

현재 산식의 백테스트는 다음 계약을 지킨다.

- 완료된 월말에만 신호 생성
- 신호일 이후 데이터는 점수 계산에 사용하지 않음
- 21·63·126거래일 이후 결과를 각각 1·3·6개월로 측정
- SPY 총수익률 대비 초과수익, 표준 11개 섹터 동일가중 대비 초과수익, 절대 양수 수익을 분리
- Top1과 Top3 동일가중 결과를 분리
- 표본 수, 평균·중앙값 초과수익, Wilson 95% 적중률 구간, 중첩 forward window용
  Newey-West/Bartlett 조정 95% 구간, 월평균 Top3 교체율 제공

V1 산식은 동일 기간·동일 데이터·동일 결과창으로 다시 계산하되
`COMPARISON_ONLY_NOT_LIVE`로만 제공한다. 과거의 별도 5년 산식은
`LEGACY_REFERENCE_ONLY`로 격리하며 현재 모델의 성능 근거로 사용하지 않는다.

### 4. 모델 경계

검증 완료 범위는 **위험조정 상대 모멘텀 레이어**뿐이다. 다음 항목은 완전한 point-in-time 이력이
쌓이기 전까지 전체 예측 적중률에 합쳐 검증됐다고 표시하지 않는다.

- 거시 국면 점수
- 애널리스트 이익 추정 revision
- 자금 흐름과 포지셔닝
- 밸류에이션과 펀더멘털 reference
- 내러티브 heat/stage

이 보조 축은 다음 주도 후보 설명과 확인 체크리스트에는 사용할 수 있지만 검증된 상대 모멘텀과 같은
신뢰 등급을 부여하지 않는다.

### 5. DDD·클린 아키텍처 배치

- `domain`: 수익률, 변동성 조정, 횡단면 순위, 추세 gate, 워크포워드 결과와 불변식
- `application`: 시계열 조회 포트 조정, 공통 기준일 구성, 유스케이스 orchestration
- `adapters`: Yahoo 수집, PostgreSQL 시계열 영속화, REST DTO 변환
- `bootstrap`: scheduler, bean 조립, 운영 설정

Domain은 Yahoo 응답, JDBC, SQL, Spring, Jackson, Controller DTO를 알지 않는다. 외부 시계열은 adapter에서
정규화된 application port 모델로 변환된 후 domain 정책에 전달한다.

## 검토한 대안

### 가격수익률 V1을 유지한다 — 기각

구현과 설명은 단순하지만 배당 차이를 무시하고 단기 잡음과 변동성 편향이 크다. 비교 기준으로는
보존하되 운영 산식으로 유지하지 않는다.

### 상용 지수 공급자의 모멘텀 지수를 그대로 사용한다 — 보류

구성 종목·기업행동·공식 총수익지수·리밸런싱 자료를 정확히 복제하려면 라이선스와 별도 데이터 계약이
필요하다. 현재 목적은 표준 섹터 ETF의 설명 가능한 내부 순위이므로 공식 지수를 복제한다고 주장하지
않는 프록시가 운영 복잡도와 투명성의 균형이 낫다.

### 거시·실적·수급을 한 점수로 즉시 백테스트한다 — 기각

현재값을 과거 시점에 대입하면 look-ahead와 revision bias가 생긴다. point-in-time snapshot이 충분히
누적될 때까지 각 레이어를 분리한다.

### Top3 평균만 대표 성능으로 사용한다 — 기각

분산 관찰에는 유용하지만 Top1과 다른 전략이다. Top1의 선택력과 Top3의 분산 효과를 별도 지표로
제공한다.

## 결과와 트레이드오프

### 긍정적 결과

- 배당이 많은 섹터도 같은 경제적 기준으로 비교된다.
- 운영 산식과 워크포워드 검증 산식이 일치한다.
- 단기 반전 잡음과 고변동성 섹터의 순위 과대평가가 완화된다.
- 시장 상승 효과와 섹터 선택 효과를 SPY·동일가중 두 벤치마크로 분리할 수 있다.
- 구형 결과가 현재 모델 성능으로 오인되는 경로가 차단된다.

### 비용과 한계

- XLC 상장 시점 때문에 표준 11개 공통 표본은 2018년 이후로 제한된다.
- 더 긴 이력이나 공식 total-return index를 사용하려면 유료 데이터 또는 합성 이력 정책이 필요하다.
- 1개월 성능은 약하며 이 모델은 단기 타이밍 도구가 아니다.
- ETF 구성 변경, 세금, 거래비용, 실제 체결 가능성은 백테스트에 포함되지 않는다.
- 변동성 조정 때문에 최근 급등 섹터가 체감 순위보다 낮게 보일 수 있으나 이는 의도된 위험 조정이다.

## 운영 불변식과 감시

- 총수익률 series: 17/17 존재; SPY+표준 11개는 하나의 원자적 단면으로 갱신
- 각 series 최소 관측치: 2,000
- 최신 공통 거래일 불일치: 0
- provider mismatch: 0
- 현재 API `methodology.version`은 V2와 일치
- `liveRelativeStrengthLayerMatched=true`
- 전체 모델이 검증되기 전까지 `fullRotationForecastValidated=false`
- 백테스트 결과에 표본 수와 95% 구간이 없으면 UI에서 적중률을 단독 노출하지 않음

무결성 위반은 last-valid snapshot을 유지하고 신규 순위 승격을 중단한다. 부분 수집 결과로 기존 정상
projection을 덮어쓰지 않는다.

## 배포·롤백

배포 전 domain/application/adapter/architecture test, 실제 PostgreSQL 다중 인스턴스 테스트, API smoke,
프론트 production build를 통과해야 한다. 배포 후 시계열 개수·최소 관측치·최신일 정렬·methodology
version을 확인한다.

문제가 발생하면 애플리케이션 이미지를 직전 버전으로 되돌릴 수 있다. V2 때문에 추가된 총수익률 이력은
append/upsert 데이터이므로 삭제하지 않는다. V1은 비교 전용으로 남아 있어 회귀 진단에 사용할 수 있지만,
별도 승인 없이 운영 순위를 V1으로 자동 전환하지 않는다.

## 결정 근거 스냅샷

2026-08-08 홈서버의 7년 월말 워크포워드 결과:

| 결과창 | V2 Top1 SPY 적중률 | V2 평균 초과수익 | V1 적중률 | V1 평균 초과수익 |
|---|---:|---:|---:|---:|
| 1개월 | 40.96% | -0.09%p | 38.55% | -0.15%p |
| 3개월 | 53.09% | +2.00%p | 49.38% | +0.38%p |
| 6개월 | 61.54% | +3.93%p | 51.28% | +1.99%p |

1개월 결과는 투자 신호로 사용하기에 약하다. V2 채택 근거는 3·6개월 결과 개선, 데이터 기준의 경제적
일관성, 산식과 검증의 일치이며 과거 적중률만을 최대화한 파라미터 탐색이 아니다.

## 재검토 조건

다음 중 하나가 발생하면 새 ADR로 이 결정을 재검토한다.

- 공식 총수익지수 또는 point-in-time 섹터 구성 데이터 계약 체결
- 최소 36개월의 거시·revision·flow point-in-time snapshot 축적
- 24개월 이상 실시간 out-of-sample에서 6개월 Top1 SPY 초과 적중률이 50% 미만
- 공급자 조정주가 정의 변경 또는 장기간 provider mismatch
- 거래비용 포함 결과가 현재 결론을 뒤집음
