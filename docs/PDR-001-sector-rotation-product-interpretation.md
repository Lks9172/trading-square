# PDR-001: 섹터 순환 신호의 제품 해석과 노출 원칙

> 이 문서에서 PDR은 **Product Decision Record**를 뜻한다.

- 문서 상태: **DECISION**
- 상태: **Accepted / production**
- 결정일: 2026-08-08
- 관련 ADR: [`../server-spring/docs/ADR-002-sector-rotation-total-return-momentum.md`](../server-spring/docs/ADR-002-sector-rotation-total-return-momentum.md)
- 상세 방법론: [`SECTOR-ROTATION-METHODOLOGY-V2.md`](SECTOR-ROTATION-METHODOLOGY-V2.md)

## 사용자 문제

사용자는 섹터 화면에서 다음 질문에 빠르게 답을 얻고 싶다.

1. 현재 실제로 강한 섹터는 무엇인가?
2. 아직 주도하지 않았지만 향후 1~3개월 또는 3~6개월에 강해질 후보는 무엇인가?
3. 점수가 높다는 것이 즉시 매수하라는 뜻인가?
4. 과거 성능은 현재 표시 중인 산식으로 검증된 것인가?
5. 현재 신호가 데이터 부족이나 구형 산식에서 나온 것은 아닌가?

기존 화면은 현재 주도와 다음 후보를 제공했지만, 상대강도·종합 순환 점수·매수 액션의 신뢰 범위가
명확히 분리되지 않았다. 특히 Top3 목록과 구형 백테스트가 모두 강한 예측 신호처럼 보일 수 있었다.

## 제품 결정

### 1. 섹터 순환은 직접 매수 신호가 아니다

섹터 순환 결과는 **자금 배분의 방향성과 기업 탐색 범위를 좁히는 상위 필터**다. 섹터가 현재 주도 또는
다음 후보라는 이유만으로 `BUY`나 `STRONG BUY`를 부여하지 않는다.

실제 기업 매수 액션은 다음 축을 별도로 통과해야 한다.

- Company Score와 B Score
- 밸류에이션 및 이익 추정 revision
- 바닥 신호와 반전 확인 신호
- 기업별 악재 해소 여부와 가이던스
- 과열·crowding·실패 위험

따라서 제품 문구는 “주도 섹터 = 매수”가 아니라 “주도 섹터 안에서 기업 후보를 우선 탐색”으로 통일한다.

### 2. 현재 주도와 미래 후보를 분리한다

| 구분 | 의미 | 기본 시간축 | 제품 행동 |
|---|---|---|---|
| 현재 주도 | 총수익률 위험조정 모멘텀과 절대 추세를 통과 | 현재~3개월 | 기업 선별 우선순위 상향 |
| 다음 후보 | 거시·상대강도·확인 체크리스트가 개선 중 | 1~3개월 | 관찰 및 확인 신호 대기 |
| 다다음 후보 | 구조적 근거는 있으나 가격 확인이 약함 | 3~6개월 | watchlist 유지 |
| 약화/이탈 | 상대강도·추세 또는 무효화 조건 훼손 | 즉시 | 신규 비중 확대 보류 |

다음·다다음 후보가 없으면 억지로 채우지 않고 빈 상태를 정상 결과로 표시한다. 예측 목록의 개수를 맞추기
위해 임계값을 자동 완화하지 않는다.

### 3. Top1과 Top3의 의미를 다르게 표시한다

- **Top1 검증축**: 해당 월말에 모델이 가장 높게 평가한 단일 섹터
- **Top2·Top3 분산 관찰**: 후보 집중 위험을 줄이기 위한 watchlist

Top3를 Top1과 같은 확신도로 표현하지 않는다. 카드와 백테스트에서 Top1·Top3 성과를 각각 표시한다.

### 4. 성능은 확률 예언이 아니라 과거 조건부 빈도다

`적중률 61.54%`는 동일한 과거 규칙에서 6개월 후 SPY를 초과한 비율이다. 다음을 뜻하지 않는다.

- 향후 반드시 61.54% 확률로 상승한다.
- 손실 가능성이 38.46%로 고정된다.
- 해당 섹터의 모든 기업이 상승한다.
- 현재 가격에서 즉시 전액 매수해야 한다.

화면에는 표본 수, 평균 초과수익, 절대 양수 수익률, 동일가중 섹터 대비 결과, Wilson 95% 구간과
중첩 forward window 조정 95% 구간을 같이 노출한다. 3·6개월은 조정 구간을 우선 해석하며 적중률만
떼어 강한 마케팅 문구로 사용하지 않는다.

### 5. 검증 범위를 명시한다

사용자에게 다음 상태를 분리해 보여준다.

- `liveRelativeStrengthLayerMatched=true`: 현재 상대 모멘텀과 백테스트 산식이 동일
- `fullRotationForecastValidated=false`: 거시·실적·수급을 포함한 전체 예측은 아직 완전 검증 아님
- V1: `COMPARISON_ONLY_NOT_LIVE`
- 과거 별도 5년 결과: `LEGACY_REFERENCE_ONLY`

검증되지 않은 축을 검증된 점수에 섞어 하나의 적중률로 보여주지 않는다.

### 6. 사용자에게 보이는 최소 정보 계약

섹터 순환 화면은 정보량을 줄이지 않고 다음을 제공한다.

- 운영 methodology version과 산식 요약
- 총수익률 데이터 사용 여부
- 현재 주도, 다음 후보, 다다음 후보, 약화 후보
- 후보별 확인 상태·점수·근거·무효화 조건
- 1·3·6개월 워크포워드 결과와 표본 수
- SPY 및 섹터 동일가중 대비 결과
- 95% 신뢰구간과 월평균 회전율
- V2와 V1의 동일 조건 비교
- 전체 모델 검증 한계와 데이터 경고

툴팁과 설명은 짧게 유지하되 상세 방법론과 ADR/PDR로 이동할 수 있어야 한다.

## 채택하지 않은 제품안

### 최고 점수 섹터에 `STRONG BUY` 표시 — 기각

섹터 상대강도는 기업의 가격·재무·악재 해소를 보장하지 않는다. 자산 액션과 섹터 순환 상태를 혼동시킨다.

### 매월 항상 다음 후보 3개 강제 노출 — 기각

근거가 약한 시기에 false precision을 만든다. 조건 충족 후보가 없으면 “현재 확인된 후보 없음”이 더 정확하다.

### 높은 과거 적중률 하나만 헤드라인으로 표시 — 기각

표본 크기, 수익 크기, benchmark 선택, 신뢰구간을 숨긴다. 과거 최적화된 숫자를 투자 확률로 오해하게 한다.

### 구형 5년 백테스트를 삭제 — 기각

역사적 의사결정과 회귀 비교에 필요하다. 삭제 대신 reference-only 영역에 격리한다.

## 성공 기준

### 기능 기준

- 화면과 API가 동일한 V2 methodology version을 표시한다.
- 현재 주도 판정은 총수익률·위험조정·절대 추세 gate를 모두 사용한다.
- V1 및 legacy 결과가 운영 신호로 합류하지 않는다.
- 데이터 부족 시 후보 수를 채우기 위한 임의 점수가 생성되지 않는다.
- 섹터 카드를 통해 관련 기업 탐색으로 이동할 수 있다.

### 데이터·품질 기준

- 표준 섹터와 benchmark 시계열이 최소 이력 계약을 충족한다.
- 워크포워드는 월말 이후 데이터만 결과 측정에 사용한다.
- 동일 기간 V1 비교와 현재 V2 결과가 재현 가능하다.
- API smoke, domain 정책 테스트, architecture test, 프론트 production build를 통과한다.

### 사용자 안전 기준

- “과거 적중률 = 미래 상승 확률”로 표현하지 않는다.
- 1개월 성능이 약한 경우 이를 숨기지 않는다.
- 섹터 상태만으로 기업 매수 액션을 생성하지 않는다.
- 데이터가 stale하거나 불완전하면 last-valid와 경고를 표시한다.

## 출시 결과 스냅샷

2026-08-08 운영 검증에서 84개 월말 신호를 평가했다.

- 3개월 Top1 SPY 초과 적중률: 53.09%, 평균 초과수익 +2.00%p
- 6개월 Top1 SPY 초과 적중률: 61.54%, 평균 초과수익 +3.93%p
- 1개월 평균 초과수익: -0.09%p
- 월평균 Top3 교체율: 24.5%
- V2 대 V1 종합 비교: `IMPROVED`

제품 해석은 **“3~6개월 상대 주도 관찰에 유용하지만 단기 매수 타이밍 확정 도구는 아님”**으로 고정한다.

## 후속 측정과 재검토

- 매월 실시간 out-of-sample 예측과 실제 1·3·6개월 결과를 immutable snapshot으로 누적한다.
- 최소 분기마다 hit rate뿐 아니라 평균/중앙값 초과수익, 회전율, 최대 불리 구간을 재검토한다.
- 거시·revision·flow point-in-time 이력이 충분해지면 별도 PDR/ADR 승인 후 전체 순환 예측 검증으로 확장한다.
- 운영 중 24개월 기준 6개월 Top1 적중률이 50% 아래로 내려가면 경고 등급을 올리고 모델 변경을 검토한다.
- 임계값이나 가중치 변경은 기존 문서를 덮어쓰지 않고 새 decision record로 남긴다.
