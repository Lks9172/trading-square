# 백테스트·모델 검증·변경 거버넌스

- 문서 상태: **CURRENT**
- 최종 코드 대조일: **2026-08-08**

## 1. 검증의 목적

백테스트는 높은 과거 적중률을 찾기 위한 장치가 아니라 다음을 확인하는 장치다.

- 현재 표시하는 규칙이 과거에도 동일하게 계산 가능한가?
- 신호 이후 수익을 신호 입력에 몰래 사용하지 않았는가?
- 시장 전체 상승이 아니라 선택 규칙이 부가가치를 만들었는가?
- 표본 수와 손실 구간을 포함해 실제 사용 가능한가?

## 2. 금지사항

- 미래 가격·반등·실적을 현재 신호 생성에 사용
- 현재 수정된 데이터나 현재 constituent를 과거 전체에 무조건 적용
- 목표가 업사이드 변화를 EPS revision으로 간주
- 가격수익률과 총수익률을 같은 이름으로 혼용
- 다른 산식의 과거 결과를 현재 모델 적중률로 표시
- 표본 수 없이 hit rate만 표시
- 여러 파라미터를 탐색한 뒤 최고 결과만 보고
- score heuristic을 통계 확률로 표시
- split/상장폐지/티커 변경을 정상 수익률로 처리

## 3. Point-in-time 계약

각 신호일에는 그 날짜까지 공개·수집 가능했던 값만 사용한다. 저빈도 데이터는 단순 관측 기준일이 아니라
실제 발표/공시 가능일을 우선한다. 동일 날짜 안 revision이 가능한 source는 revision을 보존한다.

시계열 정렬은 날짜 교집합 또는 `latest known before signal date` 방식으로 수행한다. 배열 인덱스가 같은
것을 동일 거래일로 가정하지 않는다.

## 4. 결과창

- 1개월: 21 거래일
- 3개월: 63 거래일
- 6개월: 126 거래일

만기 수익률과 기간 중 목표 수익 도달 여부는 별도다. 최대 불리 변동/낙폭도 함께 본다. 목표를 한 번
찍고 하락한 경우 목표 도달률은 높아도 만기 양수 수익률은 낮을 수 있다.

## 5. 섹터 워크포워드

- 완료된 월말에만 신호 생성
- 최근 1개월 제외 6·12개월 섹터/SPY 총수익률
- 252일 상대변동성 조정
- 이후 21/63/126거래일 측정
- SPY와 표준 11개 섹터 동일가중을 각각 benchmark
- Top1/Top3, 평균/중앙값, 양수 비율, Wilson 95% 구간, 중첩 forward window용
  Newey-West/Bartlett 조정 95% 구간, 교체율 표시
- V1은 `COMPARISON_ONLY_NOT_LIVE`
- 과거 별도 산식은 `LEGACY_REFERENCE_ONLY`

현재 전체 거시·revision·flow 순환 모델은 point-in-time 이력이 부족하므로 상대 모멘텀 레이어만 검증
완료로 표시한다.

## 6. 기업 신호 검증

기업의 바닥·반전·horizon 검증은 매 시점 과거 구간만 잘라 현재 정책을 계산한다. 미래 결과는 결과창
평가에만 사용한다.

- 가격 이력 품질을 먼저 통과
- 현재와 과거 시점의 단위를 동일하게 유지
- split형 불연속은 신호 대상에서 제외
- BUY 조건의 현재성·가격구조·거래량 gate를 과거에도 동일 적용
- 신호가 적으면 확률 대신 표본 부족 경고

최종 API의 `WALK_FORWARD`만 과거 통계다. `SCORE_HEURISTIC`은 표본이 없을 때 현재 조건을 설명하는
상대 시나리오이며 confidence 상한 39를 적용한다.

## 8. 모델 변경 절차

1. 문제와 사용자 영향 기록
2. 현재 산식 고정 baseline 생성
3. 변경 후보를 사전 정의하고 기간을 나눠 walk-forward
4. 데이터 누출·단위·split·상장 survivor 점검
5. 성능뿐 아니라 경제적 타당성·복잡도·회전율 검토
6. Domain test와 golden fixture 추가
7. ADR에 기술 결정, PDR에 제품 해석 기록
8. methodology version 증가
9. API/UI에서 구형 결과를 comparison/reference로 격리
10. 배포 후 immutable out-of-sample snapshot 누적

운영 성능이 나쁘다는 이유만으로 임계값을 즉석 완화해 후보 개수를 채우지 않는다.

## 9. 재검토 기준

- 실제 out-of-sample이 문서화한 기대 범위를 지속 이탈
- 데이터 공급자의 조정주가·revision 정의 변경
- 공식 total-return 또는 point-in-time constituent 데이터 계약 체결
- 36개월 이상의 거시·revision·flow 시점별 이력 축적
- 거래비용 포함 결과가 결론을 뒤집음
- 특정 종목/섹터의 단위 오류가 여러 시계열에서 재발

변경은 기존 문서를 조용히 덮어쓰지 않고 새 ADR/PDR 또는 명시적 version history로 남긴다.
