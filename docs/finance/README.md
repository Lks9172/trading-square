## 반드시 지킬 해석

- 점수는 **수익 확률이 아니다**.
- `STRONG BUY`도 전액 매수가 아니라 조건부 분할 접근이다.
- 바닥은 가격이 싸다는 뜻이 아니라 투매 흡수 후보이며, 반전 확인과 다르다.
- 기업이 좋아도 가격이 과열됐으면 대기할 수 있다.
- 가격이 내려도 실적 가설과 재무 품질이 훼손됐으면 물타기하지 않는다.
- stale, partial, proxy, heuristic 값은 직접·현재 증거와 같은 신뢰도로 사용하지 않는다.
- 섹터 주도는 섹터 안의 모든 기업이 오른다는 뜻이 아니다.

이 문서는 정보 제공용 모델의 내부 기준이다. 투자성과를 보장하거나 개인별 적합성을 판단하지 않는다.
