# PDR-008: 확정 섹터 후보가 없을 때 승격 전 관찰 순위를 분리 노출한다

> 이 문서에서 PDR은 **Product Decision Record**를 뜻한다.

- 문서 상태: **DECISION**
- 상태: **Accepted / production**
- 결정일: 2026-08-09
- 관련 PDR: [`PDR-002`](PDR-002-sector-rotation-evidence-disclosure.md)
- 관련 금융 플레이북: [`finance/SECTOR-ROTATION-PLAYBOOK.md`](finance/SECTOR-ROTATION-PLAYBOOK.md)

## 사용자 문제

엄격한 1~3개월·3~6개월 조건을 통과한 표준 섹터가 없으면 두 목록은 비어 있는 것이 금융적으로
정상이다. 그러나 빈 카드만 보이면 수집 장애인지, 계산 장애인지, 실제 미충족인지 구분하기 어렵고 다음에
확인할 섹터도 알 수 없다.

## 제품 결정

1. `nextCandidates`와 `secondaryCandidates`의 산식·임계값·기간 계약은 변경하지 않는다.
2. 두 확정 후보 목록이 모두 비었을 때만 `LAGGING` 섹터를 현 `rotationScore` 내림차순으로 최대 3개
   화면에서 계산해 **승격 전 관찰 순위**로 표시한다.
3. 관찰 순위에는 순환 점수, 거시 적합, 상대강도와 기존 전망 문구를 함께 표시한다.
4. 관찰 순위는 API 신호, 후보 편입, 매수 신호, 예상 확률이 아니다. UI에 `확정 후보 아님`을 바로 표시한다.
5. 데이터가 없거나 순환 계산 자체가 불가한 섹터는 관찰 순위에도 넣지 않는다.

## 사용자에게 보이는 의미

- 빈 다음/다다음 목록: “현재 기간 조건을 동시에 통과한 섹터 없음”
- 승격 전 관찰 순위: “미충족 섹터 중 현재 순환 점수가 상대적으로 높은 진단 순서”
- 행동: 후보로 선매수하지 않고 상대강도·거시·revision·공식 ETF flow의 추가 확인을 기다린다.

## 채택하지 않은 제품안

- 목록을 채우기 위해 임계값 완화: false precision과 과최적화 위험으로 기각
- LAGGING 상위 섹터를 다음 후보로 이름 변경: 기간·상태 계약을 훼손하므로 기각
- 빈 카드만 유지: 장애와 정상 미충족을 구분하기 어려워 기각

## 성공 기준과 한계

- 확정 후보가 없을 때도 사용자가 수집 오류가 아니라 미충족임을 즉시 이해한다.
- 관찰 순위가 canonical 후보 배열이나 회사 투자판단에 입력되지 않는다.
- 순위는 기존 당일 `rotationScore`의 상대 정렬이며 상승 확률로 해석하지 않는다.
- 전체 composite의 장기 point-in-time 검증이 완료되기 전에는 관찰 순위 적중률을 주장하지 않는다.

## 롤백과 재검토

클라이언트 관찰 블록만 제거하면 되며 서버 산식·API·저장 데이터에는 영향이 없다. 관찰 순위를 독립 신호로
승격하거나 API 소비자가 필요해지면 별도 금융 검증과 ADR/PDR을 선행한다.
