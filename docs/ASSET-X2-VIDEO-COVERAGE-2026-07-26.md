- 지지·저항을 피벗 군집의 **가격 구간**으로 계산
- 과거 저항→지지 또는 지지→저항 역할 전환 표시
- 고점·저점 상승/하락을 이용한 다우 추세
- 252거래일 로그 회귀 채널 하단·중단·상단과 현재 위치

- 하락 전환 3단계
  - 1단계: 모멘텀 약화
  - 2단계: 낮아진 고점/구조 균열
  - 3단계: 이전 스윙 저점 이탈
- 바닥 회복 단계
  - 바닥 다지기 → 반등 → 직전 고점 돌파 → 돌파 후 지지
- RSI 과매도는 지지/채널과 거래량 압력이 합쳐진 경우에만 confluence ON
- 지지 이탈 뒤 거래량을 동반해 복귀한 stop-hunt reclaim
- 횡보 기간과 범위로 시간 조정 표시

### 실행 연결

- 상승 구조의 채널 하단/지지 구간: 목표 비중의 30~40% 1차
- 하락 구조의 역사 지지 구간: 20~25% 이내 1차
- 채널 상단/저항 구간: 추격 제한
- 추가 진입은 높아진 저점, 직전 고점 거래량 돌파, 저항→지지 전환을 요구
- 추세 훼손 2단계는 확대 중단/축소, 3단계는 기존 상승 가설 청산 게이트
- 분할매수 전 `ScaleInEligibility`로 기업 품질·FCF·재무안정성·가이던스·논리 훼손을 먼저 판정
- 부적격/판정 불가 자산은 1차 비중 0%, 조건부 자산은 1차 20% 이하
- 적격 자산도 포트폴리오 집중 상한 7~12%를 표시해 한 종목 집중 함정을 제한

### 현재 유동성 3축·후행 발행 맥락과 신흥국 전이

- TGA 감소, RRP 감소, 은행 준비금 증가를 현재 공급 우호 방향으로 정의
- 세 축을 공급/흡수/중립 개수, -2~+2 정렬, 0~100 합치도로 각각 노출한다. 세 값은 같은 연준
  대차대조표에 연결된 확인값이므로 독립 팩터 세 개로 해석하지 않는다.
- `confidence` 호환 키는 공식 현재 입력 가용률이며 통계적 신뢰도나 수익 확률이 아님
- DXY 방향, USDKRW 구간, 코스피 외국인 수급을 추가해 미국 유동성이 한국/신흥국으로 실제 전이되는지 별도 표시
- 국채 발행은 FRED Z.1 후행 분기 순거래 프록시이므로 현재 3축 정렬에서 제외하고 별도 맥락으로만
  노출한다. 단기 경매 타이밍이나 향후 TGA 재충전 예측으로 사용하지 않는다.

### 과잉 확신 제거

- 자산 신호 화면에서 액션 enum으로 역산해 만들던 가짜 `매력`·`과열` 숫자를 제거했다.
- 조건점수는 수익 확률이 아니라 **가중 조건 충족도**라고 명시했다.
- 결측 입력은 호재로 통과시키지 않는다. 필수 입력 가중 커버리지 70% 미만은 매수·매도 단정을
  `HOLD`로 중립화하고, 70~84%는 `BUY`까지만 허용한다.
- 점수와 별도로 유동성, 꼬리위험, 이격, 가격구조 하드 게이트를 적용한다. 높은 원점수라도
  구조 훼손이나 유동성 흡수가 있으면 실제 액션은 낮아진다.
- 은·구리·신흥국은 자체 가격/거래량 또는 펀드플로 진입축이 충분하지 않으므로 거시·상대가치
  조건만으로 `STRONG BUY`가 되지 않는다.
- 레버리지는 유동성 배관, 유동성 방향, NASDAQ 이격, 꼬리위험 데이터 중 하나라도 없으면

- **회사 데이터 신선도 하드 게이트**: 7일을 넘은 가격은 신규 BUY를 허용하지 않는다. 재무 기준일

- **실행 버튼 과잉 준비 상태 수정**: 일반 BUY 또는 수급·섹터·차트 중 하나가 미확인인 STRONG BUY는

## 2026-08-06 재감사 3차 — 현재 섹터 증거와 EPS revision 정합성

- 기업 상세의 섹터 문맥이 현재 순환 overlay가 아닌 정적 카탈로그 순위를 다시 읽던 경로를 제거했다.
  회사·섹터 화면은 같은 현재 순위와 상태를 사용한다.
- 카탈로그의 날짜 없는 이익수정 점수와 거시·상대강도에서 재파생한 style flow는 각각 `참고값`,
  `수급 프록시`로 표시한다. 현재 날짜가 있는 이익추정 및 독립 수급과 동일한 확인 증거로 세지 않는다.
- 상대 순위 상위권을 `현재 주도`로 단정하지 않고 `현재 순환 상위`로 표현하며, 실제 리더십의 확인·유지

- 과거 30일 `estimateRevision`은 EPS 추정치 변화가 아니라 목표가 상승여력의 차이였다. 주가 하락이
  실적 상향으로 오인되는 문제를 막기 위해 `targetUpsideChange30d`로 분리했다.
- 실제 revision은 Yahoo `earningsTrend.epsTrend`의 forward-EPS 현재치와 7/30/90일 전 값을 사용한
  변화율만 인정한다. 0 근처 분모와 부호 전환은 결측 처리한다.
- 실제 EPS revision만 B점수의 투자매력 증감과 바닥 실패위험에 연결했다. 양(+) revision을 별도
  평균 항목으로 넣어 오히려 강한 기업의 점수가 낮아지던 산식도 증감 방식으로 교정했다.
- analyst 수집은 7개 megacap만 반환하던 제한을 제거해 표준 섹터·전략 테마 전체 ticker를 요청 시
  직접 수집·캐시하고, 시간별 PostgreSQL history universe에도 합친다. 수집 실패는 0점이 아니라
  결측/마지막 정상값으로 처리한다.
- 회사 UI는 `EPS 추정치 변화율(%)`, `목표가 상승여력 변화(%p)`, `애널리스트 점수 변화`를 서로
  다른 카드와 라벨로 노출한다.

따라서 영상에서 말하는 `기대 변화`는 가격 하락으로 기계적으로 커진 목표가 업사이드가 아니라,
실제 forward-EPS 수정·가이던스·가격/거래량 구조가 독립적으로 합치할 때만 강화 근거가 된다.

## 2026-08-06 재감사 4차 — 상세 패널의 파생값까지 단일 의미로 통일

API 핵심 필드만 바로잡아도 기존 seed에서 만들어진 하이라이트·조정 판정·투자 논리·자금 유입

- 기대치 점수와 실적 바닥은 실제 7/30/90일 forward-EPS revision만 사용한다. 목표가 상승여력과

- 상대 멀티플은 현재 EV/Sales와 catalog peer 평균·중앙값을 다시 비교하고 기준 종류를 명시한다.

  재투영한다. 기존 조정/thesis 점수는 새 결정의 입력으로 되먹임하지 않는다.
- ETF 편입·정책·내러티브 기반 capital flow는 `STRUCTURAL_PROXY`로 표시한다. 실제 펀드 순유입
  관측처럼 표현하지 않는다.
- SWR 첫 응답에서도 legacy revision 필드를 즉시 비우고 직접 EPS 수집 전에는 중립/갱신 중으로 표시한다.
